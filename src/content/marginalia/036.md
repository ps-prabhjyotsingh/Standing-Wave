A check you have never seen fail has not yet told you what it checks. It might watch the
thing you care about. It might watch something that happens to stand beside it: a server
that answers, a file that exists, a process that exits zero whether or not it did its work.
Until it goes red once, for the right reason, a green light has reported one fact, which is
that it is able to be green.
